---
description: Help me write better prompts with examples
---

I want to improve my prompting skills. For my current request:

1. **Show me examples** of similar requests written 3 different ways:
   - **Vague version** (what NOT to do)
   - **Better version** (decent but could be improved)
   - **Optimal version** (clear, specific, actionable)

2. **Explain the differences**: Why is the optimal version better?

3. **Apply to my request**: Rewrite my current request using the optimal pattern

4. **Prompting tips**: Based on my request, give me 2-3 general tips for this type of task

Format:
```
## Example Comparison

### ❌ Vague
[example of unclear request]

### ✓ Better
[example of decent request]

### ✓✓ Optimal
[example of excellent request]

## Key Differences
- [Difference 1]
- [Difference 2]
- [Difference 3]

## Your Request (Optimized)
[my request rewritten]

## Prompting Tips for This Type of Task
1. [Tip 1]
2. [Tip 2]
3. [Tip 3]
```

Then ask: "Shall I proceed with the optimized version?"
